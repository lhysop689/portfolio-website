# Portfolio Website

Personal portfolio site for Sophia Lee — Materials Science and Engineering at NTU, graduating May 2027. Built to showcase a set of data analysis and applied ML projects in one place.

**Live site:** https://lhysop689.github.io/portfolio-website/

## Pages

| File | Page |
|---|---|
| `index.html` | About / home, with expandable previews of the other sections |
| `projects.html` | Project list — description, tech stack, status, links |
| `resume.html` | Resume |
| `contact.html` | Email, LinkedIn, GitHub |

## Built with

Plain HTML and CSS. No framework, no build step, no JavaScript. Each page is self-contained, with its styles inlined in the `<head>`, and pages link to one another with ordinary relative links. Hosted on GitHub Pages, serving `main` from the repository root.

Typography is Source Serif 4 with IBM Plex Mono for labels; the palette is a warm off-white with a single muted accent.

## Editing

Edit the `.html` files and commit — GitHub Pages redeploys automatically within about a minute. Because CSS is inlined per page, a site-wide style change has to be applied to each file.

## Status

The site is live and iterating. Individual project pages, with full write-ups and findings, will be added as each project reaches a shareable state.
